# Time and Space Complexity

## Time Complexity
Time complexity describes how the execution time of a program grows with input size.

### Common Time Complexities
- O(1): Constant time
- O(n): Linear time
- O(n²): Quadratic time

### Example
A loop running from 1 to n has O(n) time complexity.

---

## Space Complexity
Space complexity describes how much extra memory a program uses.

### Example
Using an array of size n → O(n) space complexity.

---

## Why It Matters
- Helps write efficient programs
- Important for interviews
- Helps compare solutions
